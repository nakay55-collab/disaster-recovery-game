# 災害復旧・まちづくりゲーム 運営ツール一式

土木会社の合同企業説明会で行う「災害復旧・まちづくりゲーム」の進行に使う、Webブラウザだけで動くツール集です。すべてインストール不要（`index.html`を開くだけ）で、インターネット接続がなくても動作します。

各フォルダは独立したツールで、それぞれのフォルダ内の`README.md`に詳しい使い方（起動方法・操作方法・当日の運用方法）を記載しています。

## 使う順番の目安

1. **初回個人クイズ**：説明会の最初に、生徒が各自のスマートフォンでQRコードから解答する個人クイズ。正解数に応じて最初のカードセットを受け取る。
2. **PROJECT2チームクイズ**：PROJECT2開始前に、チームで相談して答える8問クイズ。正解数に応じてカードを追加獲得。
3. **工事選択順あみだくじ**：PROJECT2・PROJECT3で、5チーム（4チームにも対応）の工事を選ぶ順番をあみだくじで公平に決める。
4. **PROJECT3チームクイズ**：PROJECT3（最終ステージ）開始前のチームクイズ。5問・複数選択問題あり。
5. **追加クイズ**：すきま時間に挑戦できる「かんたん問題」「チャレンジ問題」。正解でカードを追加獲得。
6. **報酬計算・ランキング管理ツール**：進行役が各チームの工事報酬・追加クイズ費用・地域貢献ボーナスを管理し、ランキングをプロジェクターに表示する、当日メインの管理ツール。
7. **印刷用カードシート**：重機カード・人（職業）カードを、市販のマルチカード用紙に印刷するための元データと生成スクリプト。

## フォルダ構成

```
初回個人クイズ/            index.html, style.css, script.js, README.md
PROJECT2チームクイズ/       同上
PROJECT3チームクイズ/       同上
追加クイズ/                同上
工事選択順あみだくじ/       同上
報酬計算・ランキング管理ツール/  同上
印刷用カードシート/         originals/（元画像）, build_sheets.py, README.md
                          ※印刷用に生成したPNG（print-sheets/）はサイズが大きいためこのリポジトリには含めていません。
                            `originals/`の画像をもとに、フォルダ内で`python3 build_sheets.py`を実行するといつでも作り直せます。
```

## 当日の使い方（要点）

- 各ツールはPC・タブレット・スマートフォンのブラウザで動作します。生徒用の画面はスマートフォンでの利用を想定しています。
- 生徒に配布するQRコードは、各ツールをWeb公開した後の**管理者パラメータなしの公開URL**を使ってください（`?admin=1`を付けたURLは進行役専用です）。公開方法は各フォルダのREADMEにある「Web公開とQRコード」を参照してください。
- 各ツールのデータはブラウザのlocalStorageに保存されます。同じ端末・同じブラウザであれば、ページを再読み込みしても内容は保持されます。

## このリポジトリについて

このリポジトリは非公開（Private）です。ゲームの一部の裏設定（地域貢献ボーナスの対象ミッションなど）がコードに含まれているため、参加する生徒に見られないよう、公開設定には注意してください。

# 印刷用カードシート

すでに完成しているカードイラスト（8種）を、必要枚数ぶん複製してA4印刷シートに並べたものです。新しいデザインは作成していません（イラスト・配色・フレーム・レイアウトは元のまま、拡大縮小と回転のみ行っています）。

## 使用しているシート製品

**A-one マルチカード 51275（フォーマット番号 F10A4-1）**を前提にしています。

- A4サイズ、1シートに10面（2列×5行）、両面印刷対応（今回は表面のみ使用）
- カード実寸：91mm（横）×55mm（縦）、隙間なし
- 余白：左右14mm・上下11mm
- ミシン目入りで、はさみ・カッター不要

## フォルダ構成

- `originals/`：いただいた8枚の元画像
- `build_sheets.py`：シートを生成するPythonスクリプト（Pillow使用）
- `print-sheets/`：印刷用に生成した19枚のA4シート（本体）

必要枚数がすべて10の倍数なので、どのシートも同じデザイン10枚だけで構成されています（複数デザインが混ざったシートはありません）。

## カードの向きについて

シートの1面は91mm(横)×55mm(縦)の横長ですが、カード本体は55mm(横)×91mm(縦)の縦長デザインのため、**各カードを90度回転して面の中に収めています**。印刷・裁断後、カードを90度回転させて持つと、通常の向き（縦長）で読める状態になります。

## 余白について

元画像の縦横比が91×55の枠と完全には一致しないため、絵柄を一切トリミングせず、縮小して面の中央に配置する方式にしています。そのため、各カードの上下（回転前でいう左右）にわずかな白い余白が入ります。ミシン目で切り離せば、この余白は目立ちにくい位置に来ます。

## 印刷方法

1. `print-sheets/` 内の19枚のPNG（300dpi・A4サイズ）を、実寸100%（「用紙に合わせる」を使わない）でA-oneマルチカード51275に印刷してください。
2. 両面印刷はせず、片面のみに印刷してください（裏面デザインは作成していません）。
3. ミシン目に沿って折り曲げ、10枚ずつに分けてください。

## シートを作り直したい場合

`originals/` の画像を差し替えるか、`build_sheets.py` 冒頭の `CARDS` リスト（ファイル名・必要枚数）を編集してから、このフォルダで次を実行してください。

```sh
python3 build_sheets.py
```

`print-sheets/` の中身が上書きされます。

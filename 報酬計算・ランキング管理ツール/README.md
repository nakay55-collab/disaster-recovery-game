# 報酬計算・ランキング管理ツール

高校生向け「災害復旧・まちづくりゲーム」で、進行役1名が各チームの工事報酬・追加クイズ費用・順位・地域貢献ボーナスを管理するためのツールです。ブラウザだけで動作し、インターネット接続がなくても使えます。既存のクイズツール・あみだくじツール・カード印刷とは別の独立したフォルダで、他のファイルには影響しません。

## ファイル

- `index.html`：画面の土台と各種確認ダイアログ
- `style.css`：オレンジ・グリーンを基調とした、大きなボタン中心のデザイン
- `script.js`：ミッションデータ、設定、進行ロジック、保存
- `README.md`：この説明書

## 起動方法

`index.html` をブラウザ（Chrome・Safari・Edgeなど）で開くだけで動作します。インストールやサーバー設定は不要です。会場のPCで開いたまま進行してください。

複数の端末で同時に同じデータを共有することはできません（データはこの端末のブラウザだけに保存されます）。進行役は1台の端末で操作してください。

## 画面の構成

上部のタブで「PROJECT1」「PROJECT2」「PROJECT3」「最終結果」を切り替えます。右上には常に「ランキング表示」「1つ戻す」「ゲームを最初からやり直す」があります。

PROJECT1〜3の画面は、上から

1. チームを選ぶ（5チームのカード。現在の合計金額と順位も表示）
2. 選んだチームへの操作（ミッション確定・PASS・追加クイズ・手動調整）
3. ミッション一覧

の順に並んでいます。

## PROJECTの進め方（基本操作）

1. 画面上部のチームカードをタップして、担当するチームを選びます（もう一度タップすると選択解除できます）。
2. ミッション一覧から、そのチームが担当するミッションをタップします（枠が オレンジ色になり選択中と分かります）。
3. 「この工事を確定」を押すと、そのチームに報酬が自動加算されます。

一度確定したミッションは「選択済み：〇〇チーム」と表示され、他のチームは選べなくなります。同じチームが同じPROJECT内で2つ目のミッションを選ぶこともできません（先に「取り消す」が必要です）。

担当する工事がない場合は、チームを選んだ状態で「PASS（報酬0万円）」を押してください。

### 選択を間違えたとき

- ミッションカードの「取り消し」を押すと、そのミッションの報酬が取り消され、再び選択可能に戻ります（担当チームを選び直す必要はありません）。
- チームを選んだ状態で表示される「取り消す」ボタンでも同様に取り消せます。
- 直前の操作だけを戻したい場合は、右上の「1つ戻す」を使ってください（下記参照）。

## 追加クイズ費用の入力方法

工事に必要なカードが不足しているチームには、別の「カード追加クイズ」ツールで実際のクイズを行ってください。このツールでは費用の減額だけを行います。

1. 対象のチームを選びます（どのPROJECTタブからでも操作できます）。
2. 「追加クイズ −100万円」または「追加クイズ −150万円」を押します。
3. 確認画面が出るので、内容を確認して「減額する」を押すと反映されます。

## 手動調整の使い方

進行のトラブルや特別な事情に対応するため、選択中のチームに対して「＋50万円」「＋100万円」「−50万円」「−100万円」のボタンをその場で押せます。確認画面はありません（間違えた場合は「1つ戻す」で戻してください）。

## ランキングの見方

各チームカードの左上に現在の順位を表示しており、報酬が変わるたびに自動で並び替わります。同じ金額のチームは同じ順位になり（例：1位が2チームなら、次のチームは3位になります）、正しく計算されます。

### プロジェクターに映すランキング画面

右上の「ランキング表示」を押すと、順位・チーム名・合計金額だけを大きく表示した画面に切り替わります。生徒に見せるのに使ってください。「管理画面へ戻る」で元の画面に戻ります。

## 最終結果と地域貢献ボーナスの発表方法

「最終結果」タブでは、各チームのPROJECT1〜3の獲得報酬・追加クイズ費用・地域貢献ボーナス・合計金額を確認できます（「履歴を見る」で、そのチームのすべての操作履歴も確認できます）。

地域貢献ボーナスは、ゲームの最後に次の手順で発表してください。

1. 必要であれば、ボーナス金額（初期値300万円）を入力欄で変更します。
2. 「地域貢献ボーナスを発表」を押すと、対象チームの名前が画面に表示されます。**この対象チームがどのミッションによるものかは、生徒には一切表示されません。**
3. 内容を確認したら「ボーナスを加算」を押します。確認画面のあと、対象チームに一括で加算されます。
4. 一度加算すると「ボーナスを加算」は押せなくなります（二重加算防止）。やり直したい場合は「ボーナス取消」で取り消してから、金額を直して再度発表・加算してください。

その後、「最終ランキングを表示」を押すと、ボーナス加算後の最終順位を大きな画面で発表できます。

### 地域貢献ボーナスの対象について（進行役向けメモ）

PROJECT1の①・PROJECT2の⑧・PROJECT3のAは、同じ主要生活道路に関する裏設定になっています。これらのうち**いずれか1つでも**担当したチームは、全員が地域貢献ボーナスの対象になります（3つとも担当している必要はありません）。この対応関係は`script.js`内の`BONUS_LINKED_MISSIONS`という設定にのみ書かれており、画面上のどこにも表示されないようになっています。

## Undo（1つ戻す）の使い方

右上の「1つ戻す」を押すと、直前の1つの操作（工事の確定・PASS・取り消し・追加クイズ・手動調整・地域貢献ボーナスの加算）だけを取り消せます。ミッションの確定を戻した場合は、そのミッションも自動的に「未選択」に戻ります。何度でも連続して押せますが、一度に戻せるのは直前の1件だけです。

## リセット方法

右上の「ゲームを最初からやり直す」を押すと、「本当に全データを削除しますか？」という確認が出ます。「削除して最初からやり直す」を押すと、報酬・順位・選択済みミッション・履歴・地域貢献ボーナスの状態がすべて初期化されます（チーム名だけはそのまま引き継がれます）。この操作は取り消せないため、押す前に必ず確認してください。

## 保存について

チーム名・報酬・ミッションの選択状況・履歴・地域貢献ボーナスの状態は、この端末のブラウザ（localStorage）に自動保存されます。ページを再読み込みしたり、ブラウザやPCを再起動したりしても、同じ端末・同じブラウザであればデータは復元されます。保存できない環境（プライベートブラウジングなど）では、画面上部に警告が表示されます。

## 動作確認

PC・タブレット・スマートフォンのブラウザで、次の項目を確認しています。

- 各PROJECTでミッションを確定すると報酬が正しく加算される
- 同じミッションを他のチームが選べない
- ミッションの取り消しで報酬も取り消され、再選択可能になる
- 追加クイズ費用（−100万円・−150万円）が正しく反映される
- 報酬がマイナスになっても正しく表示・計算される
- ランキングが自動で並び替わり、同点順位も正しく表示される
- ①・⑧・Aを別々のチームが担当した場合、全チームが地域貢献ボーナス対象になる
- 地域貢献ボーナスは二重加算できず、「ボーナス取消」でも正しく戻せる
- 「1つ戻す」で直前の操作（ミッション確定・ボーナス加算を含む）を正しく取り消せる
- ページ再読み込み後もすべてのデータが復元される
- リセットで報酬・履歴・ミッション選択状況がすべて初期化される（チーム名は維持）

スマートフォン・タブレットでの実際の見た目については、他のツールと同じレスポンシブ設計を採用していますが、実機での最終確認をお願いします。

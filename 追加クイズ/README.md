# 追加クイズ

土木会社の合同企業説明会で使う、すきま時間用の「追加クイズ」コーナーです。チーム（PROJECT2・PROJECT3と同様に、4人×5チームなどを想定）が、タブレットまたはスマートフォン1台で「かんたん問題」か「チャレンジ問題」を選び、正解すると追加のカードを獲得できます。初回個人クイズ・PROJECT2・PROJECT3チームクイズと同じ配色（白・グレー・黄色・オレンジ）で作っており、既存のどのフォルダにも手を加えていません。外部ライブラリ・外部フォント・ビルド・サーバー側処理は不要です。

他の3つのツール（1問ずつ順番に進むクイズ）と違い、このツールは**1回の挑戦で1問だけ**ランダムに出題し、正解・不正解をすぐに判定します。挑戦後は「つぎに挑戦する」でまた選択画面に戻り、何度でも遊べます。

## ファイル

- `index.html`：画面の土台と回答確定ダイアログ
- `style.css`：スマートフォン縦画面を優先しつつ、タブレット横画面でも見やすいレスポンシブデザイン
- `script.js`：かんたん問題10問・チャレンジ問題18問のデータ、設定、タイマー、保存、出題ロジック
- `README.md`：起動・運用・変更方法

## PCで起動

`index.html` をブラウザで開けば動作します。保存の挙動を安定させるため、当日の事前テストにはHTTPでの起動を推奨します。Python 3が使える場合、このフォルダで次を実行してください。

```sh
python3 -m http.server 8003 --bind 0.0.0.0
```

初回個人クイズ（8000番）・PROJECT2（8001番）・PROJECT3（8002番）と同時に動かせるよう、ポート番号を8003にしています。PCで `http://localhost:8003/` を開きます。停止はターミナルで Ctrl+C。最近のSafari・Chrome・Edge・Firefoxを想定しています。

## スマートフォン・タブレットでテスト

1. PCとスマートフォン・タブレットを同じWi-Fiにつなぎます。
2. 上記のサーバーを起動します。
3. PCのネットワーク設定でWi-FiのローカルIPアドレスを確認します。
4. スマートフォン・タブレットで `http://192.168.1.10:8003/` のように開きます（IPは実際のPCの値に置換）。`localhost` は使いません。
5. 接続できない場合はPCのファイアウォール設定とWi-Fiの端末間通信制限を確認します。PCは起動したままにします。

公開HTTPS URLを用意できればQRコードでの配布もできます。

## 出題内容と難易度

### かんたん問題（10問からランダムに1問、正解でカード1枚）

重機の名称・基本的な安全知識・施工管理の基礎など、初回個人クイズと同じ程度の易しさの問題です。

### チャレンジ問題（18問からランダムに1問、正解でカード2枚）

単純な重機名称当てではなく、以下の3分野を参考にした、高校生には少し考えないと答えられない難易度のオリジナル問題です（実際の試験問題の転載ではありません）。

- **施工管理系**（Q1〜Q6）：施工順序・品質管理・工程管理・安全管理・採算計算など
- **運行管理系**（Q7〜Q12）：出発前点呼・距離や速度の計算・運行管理者の役割など
- **建設機械系**（Q13〜Q18）：機体重量と資格の違い・技能講習の範囲・複合的な現場判断など

選択画面では「チャレンジ　正解でカード2枚」と、小さく「施工管理・運行管理・建設機械など、実際の資格試験分野を参考にした問題が出ます」とだけ表示し、実際にどの分野の問題が出るかは出題されるまで分かりません。

## 変更する場所

`script.js` 冒頭に設定をまとめています。

- かんたん問題：`EASY_QUESTIONS` 配列の `text`・`options`・`correct`・`explanation`。正解はA=0、B=1、C=2、D=3の番号です。
- チャレンジ問題：`CHALLENGE_QUESTIONS` 配列。同じく `text`・`options`・`correct`・`explanation` に加えて `category`（`"construction"`＝施工管理／`"transport"`＝運行管理／`"machinery"`＝建設機械）を持ちます。この `category` は出題の偏りをなくすための内部管理用で、画面には表示されません。
- 正解時の獲得カード枚数：`REWARD_CARDS`（`easy: 1`、`challenge: 2`）。
- 制限時間：`CONFIG.easySeconds`（初期値45）・`CONFIG.challengeSeconds`（初期値60）。短時間の動作確認なら小さい値に変更し、管理者リセット後に開始してください。本番前に元の値に戻します。
- 保存データの識別：`CONFIG.storageKey`。問題構成を変えた際は `v2` などに変更し、旧問題の履歴が混在しないようにします。

### ランダム出題のしくみ

`pickQuestion` 関数が、保存されている出題履歴（`history`）をもとに次の問題を選びます。

- 直前に出た問題と同じ問題は選ばれません（かんたん・チャレンジそれぞれ独立に記録）。
- チャレンジ問題はさらに、直前に出た分野（施工管理／運行管理／建設機械）と異なる分野から優先的に選ばれるため、同じ分野が連続しにくくなっています（各分野6問ずつあるため、常に別の分野を選べます）。

この履歴は端末のlocalStorageに保存され、管理者リセットで消去されるまで引き継がれます。

## 進行と保存

- 選択画面で「かんたん」か「チャレンジ」を選ぶと、その場でランダムに1問が決まり、制限時間のカウントダウンが始まります。
- 回答を選んで「回答する」を押すと確認ダイアログが出て、「回答を確定する」で確定・採点します。確認中も時間は進み、時間切れが優先されます。
- 残り60秒（チャレンジのみ該当）で黄色系の強調、10秒で赤い強調になります。0秒でTIME OUTを表示し、不正解として扱われます。
- 結果画面では、正解時は「せいかい！／チャレンジ成功！」＋獲得カード枚数、不正解時は「ざんねん／チャレンジ失敗」＋「カード獲得なし」を表示し、どちらの場合も正解と短い解説を表示します。
- 同じ端末・同じURLの配信元で、現在の問題・回答・残り時間・出題履歴をlocalStorageに保持します。再読み込みしても同じ問題・同じ残り時間から再開します。
- 「つぎに挑戦する」を押すとまた選択画面に戻り、何度でも挑戦できます（正解した問題も、次に必ず出ないとは限りませんが、直前の1問とは重複しません）。

## 管理者リセット

通常URLではリセットボタンを表示しません。スタッフが同じ端末で次のURLを開くと、ページ下部に「管理者用：リセット」が表示されます。

```text
http://localhost:8003/?admin=1
https://公開先のURL/?admin=1
```

確認してリセットすると、その端末の進行状況と出題履歴をすべて初期化します。他の端末には影響しません。チーム用QRコードには `?admin=1` を含めないでください。同じタブレットを複数チームで使い回す場合は、チームが交代するたびにスタッフがリセットすると、出題履歴も新しく始まります（リセットしなくても、同じ問題が連続で出ない程度の配慮はされています）。

これは簡易的な管理機能であり、管理者認証ではありません。JavaScript内の正解閲覧、保存データ削除、別ブラウザ・プライベートモード、端末時計変更などによる不正を完全には防げません。回答は端末内だけに保存され、スタッフ向け集計や個人情報送信はありません。

## Web公開とQRコード

1. 4ファイルを同じフォルダ構成のまま静的Webホスティングへ配置します。`index.html` と同じ場所の `style.css`・`script.js` が読み込めるようにします。
2. 公開HTTPS URLを確定し、ログインなしでアクセスできることを確認します。
3. **管理者パラメータのない公開URL**をQRコードにします。
4. 実際のスマートフォンとタブレット（縦・横どちらも）でQR読み取り、文字サイズ、回答、結果表示を確認します。

公開先の契約・アカウント設定、ファイルのアップロード、公開URL確定、QRコードの作成は別途必要です。このフォルダだけではインターネット上には公開されません。

## テスト結果

以下をNode.js（`node --check`によるJS構文チェック、および純粋なロジックを取り出したデータ検証・jsdomによる実際のHTML/JS実行）で確認しました。

- チャレンジ問題18問すべて：正解の選択肢番号が選択肢の範囲内にあり、選択肢の重複がないこと。
- 計算問題（Q9・Q10・Q11・採算のQ6）の答えが正しいこと（48×1.75＝84km、150÷3＝50km/h、120÷60時間＋30分＝2時間30分、900－200＝700万円 vs 750万円で差50万円）。
- チャレンジ問題の分野が施工管理・運行管理・建設機械それぞれ6問ずつであること。
- ランダム出題ロジックを1000回（データ単体）・60回（実際のアプリの選択→時間切れ→再挑戦のサイクル）実行し、同一問題の連続・同一分野の連続がいずれも0回であること。
- かんたん問題は45秒、チャレンジ問題は60秒でタイマーが開始すること。
- 未回答での「回答する」でエラー表示、正解時「せいかい！／チャレンジ成功！」＋カード枚数、不正解時「ざんねん／チャレンジ失敗」＋「カード獲得なし」＋正解・解説の表示、TIME OUT表示と不正解扱いを確認。
- 再読み込みしても同じ問題・同じ残り時間で再開されること（タイマーが最初に戻らないこと）。

画面の見た目（スマートフォン幅での崩れの有無）は、初回個人クイズ・PROJECT2・PROJECT3で確認済みと同じCSS設計（`options`のレイアウト、`@media`によるスマートフォン・タブレット向け調整）を踏襲していますが、この環境の制約で実機・スクリーンショットでの最終確認はできていません。実機での見た目確認をお願いします。
